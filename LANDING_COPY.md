## FAQs

### Does this connect to my billing systems?

No. The current version uses manual inputs so teams can audit spend without granting billing access.

### Is company data shared in public reports?

No. Shared audit URLs remove company name and email, keeping only anonymized savings data.

### Are savings guaranteed?

No. The app uses rule-based recommendations from current pricing research. Teams should verify usage and contract details before changing plans.

### What happens if savings exceed $500/month?

The app shows a consultation CTA because the potential savings are large enough to justify a deeper review.

### Which tools are supported?

ChatGPT, Claude, GitHub Copilot, Cursor, Gemini, Windsurf, and v0.
